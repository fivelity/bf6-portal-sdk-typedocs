# Installation & Setup

## Requirements

- Node.js 20 or newer
- A Portal project with access to the official SDK package
- A GitHub repository if you want automatic publishing

## Install the SDK

```bash
npm install bf6-portal-sdk
```

The package is designed to run alongside the Portal runtime. Its object helpers expect the global `mod` API provided by the game environment.

## TypeScript setup

Point your TypeScript project at the SDK declarations and keep strict checking enabled where possible. The generated API reference is based on exported symbols, so add JSDoc to your own wrappers when you want their intent to be visible to teammates.

## Documentation site

This site uses TypeDoc to turn the SDK entry point into Markdown, then VitePress turns the Markdown into the published site. Guides are hand-written; the API directory is regenerated by automation.
